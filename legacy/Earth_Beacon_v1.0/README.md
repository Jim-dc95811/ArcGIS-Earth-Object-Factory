# Earth Beacon v1.0 — Legacy Standalone Tool

This folder preserves the accepted standalone Earth Beacon v1.0 source and documentation.

Earth Beacon was the first object/navigation experiment that grew into the broader **ArcGIS Earth Object Factory**.

The original standalone release remains available at:

`../../releases/Beacon_Maker_v1.0.zip`

Do not treat the legacy source here as the active Object Factory code. The Beacon capability now exists as one of the main Object Factory tabs.
