# Changelog

## Earth Beacon / Beacon Maker v1.0 — 2026-10-27

First accepted release.

- Creates vertical KML beacons for ArcGIS Earth
- Manual latitude/longitude input
- Windows clipboard coordinate input
- ArcGIS Earth camera-coordinate input through the local Automation API
- Auto / Lat-Lon / Lon-Lat clipboard order handling
- explicit Swap Lat/Lon control
- configurable beacon height
- configurable line width
- seven selectable colors
- optional automatic opening of the saved KML
- built-in parser/KML self-test
- standard-library Python only

Live-verified in ArcGIS Earth with a horizon-visible red beacon.
